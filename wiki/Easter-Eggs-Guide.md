## 🦨 Skunk Works (Lockheed Martin)

These commands pay homage to Lockheed Martin's legendary Skunk Works division, known for developing the world's most advanced aircraft.

### `blackbird`
View all legendary Skunk Works aircraft projects.

**Displays:**
- **A-12 OXCART** - CIA's Mach 3+ spy plane (1962)
- **SR-71 BLACKBIRD** - Still holds speed records (Mach 3.3+)
- **U-2 DRAGON LADY** - High-altitude surveillance (still in service!)
- **F-117 NIGHTHAWK** - First stealth fighter
- **F-22 RAPTOR** - Air superiority stealth fighter
- **F-35 LIGHTNING II** - Multi-role stealth fighter

Each aircraft includes:
- First flight year
- Top speed/altitude
- Key capabilities
- Service status

### `skunkworks`
Read Kelly Johnson's legendary 14 Rules of Management.

**Features:**
The principles that guided the Skunk Works' most advanced development programs, including:
1. Complete project control for the manager
2. Small but strong project offices
3. Restricted team size ("in an almost vicious manner")
4. Simple drawing and release systems
5. Minimum reports, thorough documentation
10. Strictly controlled access
14. Small team with complete mutual trust

**Quote:** "Be quick, be quiet, be on time." — Kelly Johnson

### `sr71`
Learn about the Skunk Works philosophy.

**Displays:**
- "Innovation at the speed of need!"
- Kelly Johnson's inspirational quote about doing what others say you can't
- Commands to explore: `blackbird` and `skunkworks`

## ☕ Developer Humor

### `coffee` or `brew`
ASCII art coffee mug because developers run on caffeine.

**Output:**
```
      ☕
    ~~~~~~~~~~~~
    )  ~~~~~~  (
    )  COFFEE  (
    )__________(
    |__________|

   A developer's best friend.
   Current status: Caffeinated ✓
```

**Fun Fact:** The `brew` command is a reference to Homebrew, the macOS package manager.

### `vim` or `:q`
How to exit Vim - the eternal developer struggle.

**Related Commands:** `:q!`, `:wq`

**The Joke:** Vim is notoriously difficult to exit for newcomers. There are literally Stack Overflow questions with millions of views asking "How do I exit Vim?"

**Pro Tip:** This easter egg provides a step-by-step guide, including "Question your life choices."

### `hello world`
The classic first program every developer writes.

**Variations:** `hello, world`, `helloworld`

**Shows:** Code examples in multiple languages:
- C: `printf("The classic first program!");`
- JavaScript: `console.log("Every journey starts here");`
- Python: `print("Welcome, fellow developer!")`

**Nostalgia Factor:** 💯

### `sudo`
Try to run sudo commands... get denied!

**Variations:** `sudo su`, `sudo rm`

**Output:**
```
🔐 Nice try...

   David is not in the sudoers file.
   This incident will be reported.

   (Just kidding, I'm a portfolio website)
```

**Reference:** This mimics the actual Linux error message when a user without sudo privileges tries to run elevated commands.

### `rm -rf`
The most dangerous Linux command... safely contained.

**Variations:** `rm -rf /`, `rm -rf /*`

**What it does in real life:** Recursively force-deletes everything from the root directory. Never run this on a real system!

**Output:**
```
💀 Whoa there, cowboy!

   I see you like to live dangerously.
   Fortunately, this terminal is read-only.

   Your destructive tendencies have been noted.
   HR will be in touch.
```

### `make me a sandwich`
Classic XKCD #149 reference.

**The Comic:** A user asks the computer to make them a sandwich. Computer says no. User tries with `sudo`...

**Without sudo:**
```
🥪 What? Make it yourself.
```

**With sudo:** Type `sudo make me a sandwich` to see the magic happen! The computer obeys and builds you a sandwich with ingredients:
- 🍞 Bread
- 🥬 Lettuce
- 🍅 Tomato
- 🧀 Cheese
- 🥓 Bacon
- 🍞 Bread

**XKCD Link:** https://xkcd.com/149/

## 🎯 Hidden UI Easter Eggs

### Hidden Navigation
On desktop, hover over the `<>Full Stack Vibes` logo to reveal hidden navigation that expands between the brackets:

**Default:** `<>Full Stack Vibes`

**On Hover:** `< Home | Projects | Resume | Contact | Themes >Full Stack Vibes`

**Animation:** Smooth 500ms transition

### Theme Dropdown
Hover over "Themes" in the navigation to see a dropdown with color swatches for all 6 themes.

### Auto-Expanding Nav
On page load, the navigation automatically expands for 2 seconds then collapses, giving new visitors a hint about the hidden menu.

### Terminal Auto-Reset
The terminal history automatically fades out and clears after 20 seconds of inactivity. Watch for the smooth fade animation!

### Clickable Command Hints
All the command hints at the bottom of the terminal are clickable buttons that execute the commands with a 1-second delay for better UX.

### Modal Command Execution
In the Easter Eggs modal, every command card is clickable - click to close the modal and execute the command instantly!

**How it works:** Uses arrays of common typos and fuzzy matching algorithms to help users find the right command.

## 💡 Creating Your Own Easter Eggs

Want to add your own easter eggs to the code? Here's how:

1. Open `components/Hero.tsx`
2. Find the `executeCommandAction` function
3. Add a new case in the switch statement:

```typescript
case 'your-command':
  setCommandHistory(prev => [...prev,
    '',
    '🎉 Your Easter Egg Message!',
    '',
    '   Add your creative content here',
    ''
  ]);
  break;
```

4. Add it to the Easter Eggs modal in `components/EasterEggsModal.tsx`
