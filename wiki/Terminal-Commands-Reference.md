# Terminal Commands Reference

The terminal interface supports 30+ interactive commands. Type any command in the input field and press Enter to execute.

## 📋 Quick Reference

Click the command links at the bottom of the terminal, or type them manually:

```
help | projects | career | contact | resume | github | linkedin | ai | theme | eastereggs | clear
```

---

## Navigation Commands

### `help` or `/help`
Displays the help menu with available commands and a random movie/book quote intro.

**Example:**
```bash
> help
Ask and you shall receive... Here are the sacred commands:
```

### `projects` or `/projects`
Scrolls to the projects section and restores the projects terminal if closed.

**Random messages include:**
- "One does not simply scroll to projects... But here we go!"
- "The spice must flow... to the projects section!"
- "Engaging hyperspace jump... Projects ahead!"

### `career` or `/career`
Scrolls to the career timeline section.

**Aliases:** `experience`, `history`, `timeline`

**Random messages include:**
- "git log --career | The full commit history of my professional journey!"
- "From design ops to AI applications... Let me show you the path!"

### `contact` or `/contact`
Scrolls to the contact section and restores the contact terminal if closed.

**Random messages include:**
- "You shall not pass... without saying hello first!"
- "Help me, Obi-Wan... You're my only hope! (Or just email me)"

### `resume` or `/resume`
Opens the resume modal with PDF download option.

**Aliases:** `/cv`, `cv`, `download`

**Random messages include:**
- "My precious... I mean, my resume! Here it is!"
- "Do or do not download my resume... There is no try!"

## Fuzzy Matching

The terminal includes smart typo detection! If you mistype a command, it will suggest the correct one:

**Examples:**
- `hlep` → "Did you mean 'help'?"
- `dakr` → "Did you mean 'dark' mode?"
- `projet` → "Did you mean 'projects'?"
- `easter egg` → "Did you mean 'eastereggs'?" (with clickable link!)

---

## Command Tips

1. **Case Insensitive** - All commands work in any case: `HELP`, `help`, `HeLp`
2. **Multiple Variations** - Many commands have aliases (e.g., `resume` = `/resume` = `cv`)
3. **Random Messages** - Most commands show different messages each time
4. **Clickable Hints** - Click commands at the bottom of the terminal
5. **Auto-Reset** - Terminal history clears after 20 seconds of inactivity
6. **Mobile Friendly** - All commands work on mobile devices
