**FullStackVibes** is an interactive, terminal-themed portfolio website showcasing enterprise applications, AI-powered tools, and over a decade of software development experience. Built with modern web technologies and designed for developers who appreciate attention to detail.

## 🌟 Key Features

- **Interactive Terminal Interface** - Real command-line experience with 30+ working commands
- **Multi-Theme System** - 6 unique color themes with light/dark mode support
- **Easter Eggs** - Hidden commands and surprises for curious visitors
- **AI Chat Assistant** - Built-in AI chatbot powered by Claude
- **Responsive Design** - Seamless experience across all devices
- **Static Export Ready** - Fast, SEO-optimized static site generation

## 🎯 What This Portfolio Showcases

- **3 Private Enterprise Applications** - init_VUE, leg_VUE, sp_VUE
- **AI-Augmented Development** - $400K+ in cost savings, 80% efficiency gains
- **12+ Years Experience** - From Design Ops to Solutions Architecture
- **Modern Tech Stack** - Go, Python, TypeScript, React, Next.js, FastAPI

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/d4vid4nderson/fullstackvibes.git

# Install dependencies
cd fullstackvibes
npm install

# Run development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) and start exploring!
